# Agulhas Labs Homebrew tap

```sh
brew install agulhas-labs/tap/sift
brew install agulhas-labs/tap/simwalk
```

| Formula | What it is |
| --- | --- |
| [`sift`](https://github.com/Agulhas-Labs/sift) | Swift code index and build/test runner for AI coding agents (Apple Silicon) |
| [`simwalk`](https://github.com/Agulhas-Labs/simwalk) | Deterministic UI walks of a running iOS app, for coding agents and people (Apple Silicon, needs Xcode) |

Each formula is generated from its project's release; changes go to the project, not here.
